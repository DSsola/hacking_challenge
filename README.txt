BLACK//VOID — DATA HEIST (v6.0)
================================

GitHub Pages에서 실행할 수 있는 모바일 가로 화면용 브라우저 게임입니다.

[GitHub Pages 배포]
1. 이 ZIP을 압축 해제합니다.
2. BLACK_VOID 폴더 안의 index.html, css 폴더, js 폴더를 GitHub 저장소에 업로드합니다.
3. 저장소 Settings > Pages에서 배포 브랜치와 /(root)를 선택합니다.
4. 생성된 GitHub Pages 주소로 접속합니다.

[게임 핵심]
- 가상 네트워크 노드 침투: 노드를 선택하고 4자리 보안 코드를 뚫습니다.
- 작전 의뢰, 암호 해독, 보안 인증, 데이터 업로드
- TRACE가 높아지면 가상 경보가 발생합니다.
- 장비를 구매해 에너지 소비, 추적, 보상을 개선합니다.
- 랭크, 연속 침투, 데이터 루팅 기록이 저장됩니다.

[데이터 화폐]
게임 내부 화폐는 Byte를 기본값으로 저장하고, 보유량에 따라
Byte → Bit → Kilobyte → Megabyte → Gigabyte 등급으로 표시합니다.
이것은 게임 밸런스를 위한 가상 화폐 등급이며 실제 컴퓨터 데이터 단위 변환과는 다릅니다.

[주요 터미널 명령어]
help       명령어 목록
scan       가상 네트워크 스캔
map        네트워크 지도 열기
connect 1  지정 노드 침투 시작 (1~6)
probe      선택 노드 정보 조사
breach     선택 노드 침투
decrypt    암호 연구소
upload     데이터 10 KB를 판매
trace      추적 상태 확인
loot       침투/연속 기록 확인
missions   작전 의뢰
shop       장비 상점
recover    에너지 회복 및 추적 감소
status     상태 확인
save       저장

[저장]
게임 진행은 localStorage를 사용해 현재 브라우저에 저장됩니다.
다른 기기/브라우저와 자동 동기화되지는 않습니다.
실제 네트워크나 타인의 시스템에 접속하지 않는 가상 해킹 게임입니다.
